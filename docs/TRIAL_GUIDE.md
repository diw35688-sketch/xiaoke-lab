# 小科 · 实验室试用说明

> 给第一次用它的同学：**5 分钟装上，边做实验边说话，它替你记。**

---

## 一、它是什么（30 秒版）

做实验时手是湿的、戴着手套、盯着试管——不方便停下来打字。小科让你**直接说话**：

```
你：先加 5 毫升缓冲液，然后 60 度水浴 10 分钟
小科：记下了。溶液中 NaCl 浓度按 0.5 摩尔算对不对？
你：对
小科：好，已记。需要我起个 10 分钟计时吗？
```

它不只是记笔记，还能：
- **查配方/引物**：你说"ABC 的引物是什么"，它从实验室上传的表里查
- **算浓度**：你问"配 500mL 0.1M NaCl 要多少克"，它调计算器算，不猜
- **盯时间**：说"离心 10 分钟"，到点它会提醒你
- **主动提醒**：每天早上检查库存有没有快过期的试剂

---

## 二、你需要准备什么

| 你需要的 | 说明 |
|---------|------|
| 一台 Windows 电脑 | 实验室电脑就行 |
| 一个模型 API Key | 让它能"听懂"话，需要你自己申请一个（DeepSeek 或通义千问都行，几块钱能用很久） |
| 麦克风 | 电脑自带或耳机都行 |

**注意**：你的实验数据全部存在**你自己电脑本地**（一个 SQLite 文件），不会上传到任何服务器。模型 API 只用于理解你说的那句话。

## 三、三步开始（Windows）

**第 1 步：下载**

打开 https://github.com/diw35688-sketch/xiaoke-lab ，点绿色 `Code` 按钮 → `Download ZIP`，解压到一个**不含中文的路径**（比如 `D:\xiaoke`）。

**第 2 步：启动**

双击解压后文件夹里的 `start.bat`。

- 第一次运行会自动装依赖（需要 5-10 分钟，等它跑完）
- 以后每次用还是双击这个文件

**第 3 步：填 API Key**

启动后浏览器会自动打开界面 → 点右上角 **设置** → 把申请到的 API Key 粘进去 → 保存。

**完成。** 现在点麦克风，说"你好"试试。

## 四、建议第一次这样用它

按这个顺序试一遍，10 分钟就能摸清它：

| 步骤 | 你说什么 | 它会做什么 |
|------|---------|-----------|
| 1 | 「你好」 | 打招呼，确认语音链路通了 |
| 2 | 「配 500 毫升 0.1 摩尔的 NaCl 要称多少克」 | 调计算工具，给你克数（不是猜的） |
| 3 | 「ABC 的引物是什么」 | 查知识库（前提：引物表已上传） |
| 4 | 「我要做质粒提取」 | 搜索方案 → 选一个 → 出准备清单 |
| 5 | 「开始做」→ 按方案操作并口述 | 逐步记录，缺参数会追问 |
| 6 | 「离心 10 分钟」 | 起计时器，到点提醒 |
| 7 | 「今天做到这里」 | 生成今天的小结 |

## 五、上传你实验室的资料（可选但推荐）

**引物表**：左侧导航 → **知识库** → 上传 Excel/CSV。以后问"XX 的引物"就能直接查到。

**实验方案**：左侧导航 → **实验方案** → 上传 PDF 或直接让 AI 生成。以后做这个实验可以按步骤走，它会核对数据。

## 六、常见问题

**Q：说话它没反应？**
检查设置里的 API Key 填了没；确认麦克风权限给了浏览器；试试在界面里直接打字（打字和说话走同一套流程）。

**Q：它记错了怎么办？**
口述记录它**不会覆盖你的原话**——原始语音文本和结构化结果分开存。你可以直接说"刚才那个记错了，应该是 60 度"，它会补一条修正记录。

**Q：数据存在哪？会上传吗？**
存在你电脑的 `data/` 目录下（SQLite 文件），**不自动上传**。只有你说话的那句话会发给模型 API 做理解。

**Q：能几台电脑一起用吗？**
可以。一台做主机启动，其他设备用手机/电脑连同一个局域网访问（启动时会显示二维码）。

**Q：装不上怎么办？**
把报错截图发我，或者在 GitHub 提个 issue。
