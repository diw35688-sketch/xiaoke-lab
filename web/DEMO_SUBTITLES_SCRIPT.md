## 四、配音指导

| 段落 | 情绪 | 语速 | 音色参考 |
|------|------|------|---------|
| 第一幕 0:00–0:36 痛点 | 压抑、无奈、轻微焦躁 | 偏慢，有停顿 | 低沉男声，带叹息感 |
| 第二幕 0:36–1:00 转折 | 好奇、期待、渐亮 | 由慢转中速 | 同一人，语气上扬 |
| 第三幕 1:00–2:00 实验 | 专注、从容、快节奏 | 中速偏快 | 干净利落，像解说 |
| 第四幕 2:00–2:48 计算 | 自信、清晰、强调 | 中速，重音落在数字 | "0.782克" 要念清楚 |
| 第五幕 2:48–3:12 计时器 | 轻松、对比感 | 中速 | "它替你盯着" 带微笑感 |
| 第六幕 3:12–3:36 检索 | 干脆、自豪 | 偏快 | "搜一下就行" 自信 |
| 第七幕 3:36–4:12 复盘 | 温暖、沉静、走心 | 偏慢 | 温柔，像晚安 |
| 第八幕 4:12–5:00 升华 | 充满希望、坚定 | 慢，有力 | 收尾金句要掷地有声 |

> **建议**：旁白用一个人录全部，后期调整情绪。或用 AI 配音（如 Azure TTS 中文男声 zh-CN-YunxiNeural 或 zh-CN-YunjianNeural），但收尾金句建议真人录，更有感染力。
